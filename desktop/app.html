申请步骤

  1. 打开高德开放平台控制台并登录。
  2. 进入应用管理，创建应用并添加「Web 服务」类型 Key。
  3. 复制 Key 到下方保存。无需填写 JS API 安全密钥。

📁 选择数据文件夹（推荐）

点击主界面的「选择数据文件夹」，选一个专门的空文件夹。之后新建的旅行记录、笔记和照片会保存到这里，方便备份或迁移电脑。软件会尝试记住此位置，下次启动时可能需要重新授权。

想备份时，先关闭软件，再复制整个数据文件夹。

💾 不选择文件夹时

记录和照片保存在当前 Windows 用户的应用本地存储中，不在安装目录，也不会自动同步到云端。卸载或清理应用数据可能造成数据丢失，建议定期使用「导出数据」备份；浏览器存储模式下，照片数据也会包含在导出的记录中。

🔑 地点搜索 Key

点击「地图设置」，按步骤申请高德「Web 服务」Key 并保存。没有 Key 时仍可浏览地图、添加记录；搜索地点需要 Key。之后可在此替换或清除。

🗺️ 中国地图与全球地图

中国模式使用高德地图，全球模式使用 OpenStreetMap。地图均需联网；全球底图无需申请 Key。高德搜索 Key 仅用于地点搜索。
